## How to link from my website (so I remember later)
Use GitHub’s preview URL or a direct download:

- Preview (on Github): *(use this one with code files)*  
  `https://github.com/leeannvidal/leeannvidal.github.io/blob/main/<PATH-TO-FILE>` *(it's just the normal link to the file)*
- Direct view without Github look *(Use this one with PDFs, when used with code files, it forces a direct download)*
    https://leeannvidal.github.io/PATH-TO-FILE
- Direct download:  
  `https://raw.githubusercontent.com/leeannvidal/leeannvidal.github.io/main/<PATH-TO-FILE>`

Replace `<PATH-TO-FILE>` accordingly.
